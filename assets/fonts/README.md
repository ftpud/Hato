# JetBrains Mono

Bundled from https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/ttf
(version 2.304). Original, unmodified Regular, Medium, SemiBold, Bold and Italic
faces. Distributed under the SIL Open Font License in OFL.txt.

The native text system registers these assets at startup. Font selection and
weight defaults live in sdk/typography.ts and the workspace-layout module.
